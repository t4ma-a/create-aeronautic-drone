  ### -- now i tell how to start drone-- 

1. **First download schematic and drop file in `minecraft/schematics` then use the schematic table to make a schematic and place it.**

2. **After make any file in top and bottom pc for example write "edit program" then run the `id`command on the bottom and top PCs ,remember to close the computer and go to `minecraft/saves/"your_world"/
computercraft/computer/` select the folder with the ID name of the top PC and drop the file `sender PID` to it .**

3.**Find folder with the name of bottom pc and drop file `PID` to it. After in game click to bottom pc and write command `PID` , in top pc write command `sender PID` .**
4. **Drone will start, to control it link controller to transmitters in bottom.**
